DOC.REF // MV3-774

SYSTEM
PARAMETERS

Directives for bridging the gap between browser sandbox and the local MPV kernel. Paste these commands into your configuration terminal.

CLASSIFIED LEVEL 4

MPV.CORE // General CLI Flags

Paste these into the CUSTOM_CLI_FLAGS box.

01
Force Fullscreen
Initializes the viewport in absolute fullscreen mode instantly upon execution.
--fs
02
Absolute Volume Override
Sets the starting volume level. Accepts values from 0 to 130.
--volume=80
03
Dynamic Autofit
Constrains the initial window size to a percentage of the screen dimensions.
--autofit=50%
04
Save Position on Quit
Automatically commits playback state and timestamp to disk upon termination.
--save-position-on-quit
05
Z-Index Lock
Forces the player window to remain persistently above all other OS windows.
--ontop

YT.FORMAT // Stream Format Strings

Paste these into the YTDL_FORMAT box.

06
1080p Resolution Cap
Throttles the stream negotiator to a maximum of 1080p.
bestvideo[height<=1080]+bestaudio/best
07
720p Bandwidth Saver
Aggressive throttle for constrained network environments.
bestvideo[height<=720]+bestaudio/best
08
Nullify Video Render
Extracts and streams only the audio track.
bestaudio/best

YT.ADV // Advanced Directives

Paste these into the CUSTOM_CLI_FLAGS box.

09
Mark Watched
Forces YouTube to update your account history. Requires "Pass Identity" enabled.
--ytdl-raw-options="mark-watched="
10
Hardware Acceleration (VAAPI)
Forces VAAPI hardware decoding. Essential for Linux systems with Intel/AMD GPUs.
--hwdec=vaapi
11
Streaming Cache
Enables aggressive caching for high-bitrate streams to prevent buffering.
--cache=yes
12
Subtitle Auto-load
Automatically loads external subtitle files that match the video filename.
--sub-auto=fuzzy

YT.TROUBLE // Troubleshooting

13
Native Host Not Found
Ensure the native host manifest is in the correct browser config directory and the extension ID matches.
./installer.sh
14
Cookies Not Passing
Ensure "Pass Identity" is enabled in Options. Note: Chromium-based browsers may block cookie access for security.
--pass-identity=true
15
Stream Not Detected
Check if the HLS sniffer is enabled. Some sites use non-standard manifest delivery.
--snifferEnabled=true
