DOC.REF // MV3-774

SYSTEM
PARAMETERS

Directives for bridging the gap between browser sandbox and the local MPV kernel. Paste these commands into your configuration terminal.

CLASSIFIED LEVEL 4

MPV.CORE // CLI Overrides

01
Force Fullscreen
Initializes the viewport in absolute fullscreen mode instantly upon execution.
--fs
02
Absolute Volume Override
Sets the starting volume level. Accepts values from 0 to 130.
--volume=80
03
Dynamic Autofit
Constrains the initial window size to a percentage of the screen dimensions while maintaining aspect ratio. Prevents massive video resolutions from overflowing the screen.
--autofit=50%
04
Save Position on Quit
Automatically commits playback state and timestamp to disk upon termination. Resumes seamlessly from the exact position on next execution.
--save-position-on-quit
05
Z-Index Lock
Forces the player window to remain persistently above all other OS windows.
--ontop

YT.EXTRACT // Stream Directives

06
Mark Watched
Forces YouTube to update your account history and mark the stream as "watched". Requires browser identity forwarding (cookies) to be active. Place this in the CUSTOM_CLI_FLAGS box.
--ytdl-raw-options="mark-watched="
07
1080p Resolution Cap
Throttles the stream negotiator to a maximum of 1080p for optimized buffering. Place this in the YTDL_FORMAT box.
bestvideo[height<=1080]+bestaudio/best
08
720p Bandwidth Saver
Aggressive throttle for constrained network environments. Limits stream to 720p. Place this in the YTDL_FORMAT box.
bestvideo[height<=720]+bestaudio/best
09
Nullify Video Render
Extracts and streams only the audio track. Ideal for podcast streams and music. Place this in the YTDL_FORMAT box.
bestaudio/best
